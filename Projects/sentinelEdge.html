SentinelEdge : sécurité Linux embarquée

  • Linux embarqué, C et cybersécurité
  • BeagleBone Black
  • Projet personnel — Autoformation

SentinelEdge est un projet de cybersécurité embarquée visant à concevoir un système de surveillance et de détection d'activités suspectes sur Linux. L'objectif est de développer un agent léger en C, capable de collecter des informations sur le système, de détecter des comportements anormaux et de transmettre des alertes à une interface de supervision.

Linux embarqué Cybersécurité BeagleBone Black C Détection d'intrusion

Agent de surveillance système

C & Linux

Développement prévu d'un agent léger en C destiné à fonctionner directement sur la carte BeagleBone Black.

  • Collecte de métriques système : utilisation du processeur, mémoire et processus actifs.
  • Surveillance de certains événements et changements observables sur le système.
  • Conception de règles permettant de repérer des activités potentiellement suspectes.
  • Gestion des erreurs et limitation de l'impact de l'agent sur les ressources embarquées.
C Linux /proc Processus Métriques système

Détection d'activités suspectes

Détection d'intrusion & analyse système

L'objectif est de mettre en place des mécanismes de détection adaptés aux contraintes d'un système Linux embarqué.

  • Définition de règles de détection à partir des événements et métriques collectés.
  • Identification de comportements inhabituels, selon des seuils et des conditions configurables.
  • Génération d'alertes contenant les informations utiles à l'analyse.
  • Préparation de scénarios de test contrôlés pour vérifier le comportement du système.
Détection d'anomalies Analyse de logs Règles de sécurité Alertes Tests

Service Linux et fonctionnement autonome

systemd & administration Linux

  • Préparation d'un service systemd pour gérer le démarrage et l'arrêt de l'agent.
  • Configuration des journaux et des paramètres de fonctionnement.
  • Étude des permissions nécessaires et réduction des privilèges lorsque cela est possible.
  • Vérification du comportement du service après un redémarrage de la carte.
systemd Services Linux Permissions Journalisation Débogage

API sécurisée et supervision

API, TLS & interface web

Une interface de supervision est envisagée pour consulter l'état du système et visualiser les alertes générées par l'agent.

  • Conception d'une API pour transmettre les métriques et les alertes.
  • Prévision de communications protégées par TLS.
  • Création d'un tableau de bord web pour afficher les informations utiles.
  • Préparation de tests pour vérifier les échanges et la gestion des erreurs.
API TLS HTTP HTML / CSS / JavaScript Supervision
