Naviguard : Analyse et Modélisation de données AIS

Projet d'analyse et de modélisation des données de navigation maritime (AIS) du Golfe du Mexique, de l'extraction des données brutes jusqu'à une plateforme web de visualisation, en passant par des modèles d'intelligence artificielle. Il s'articule autour de trois phases majeures.

Extraction et Big Data

R

  • Traitement de flux de données brutes AIS du Golfe du Mexique : suppression des données erronées et gestion des valeurs manquantes.
  • Filtrage des données par zone géographique et reconstruction des trajectoires de navigation.
  • Application de modèles de régression pour analyser les comportements de navigation, et production de statistiques descriptives.
  • Génération de fichiers structurés (CSV) optimisés pour la consommation par les modèles d'intelligence artificielle.
R Big Data Données AIS Régression CSV

Intelligence Artificielle

Python

  • Clustering non supervisé (K-Means) pour regrouper les navires par comportements similaires.
  • Modèles de classification supervisée (Random Forest) pour prédire le type de navire à partir des paramètres de navigation.
  • Calcul et analyse des métriques de précision pour valider la robustesse des modèles prédictifs.
  • Scripts Python utilisables en ligne de commande pour automatiser le cycle d'apprentissage.
Python K-Means Random Forest Classification Métriques de performance

Plateforme Web et Visualisation

Full-Stack

  • Maquettage et design UX : conception d'une interface intuitive et d'une charte graphique dédiée au projet.
  • Développement front-end en HTML5/CSS3, avec JavaScript pour les comportements interactifs.
  • Back-end PHP : scripts serveur pour l'encapsulation des données et la gestion des requêtes utilisateur.
  • Cartes et graphiques interactifs (Plotly, Mapbox) pour explorer les trajectoires dans l'espace.
  • Requêtes asynchrones (AJAX) pour une communication fluide entre l'interface et la base de données.
  • Modélisation (MCD) et implémentation du schéma de base de données SQL pour le stockage des logs maritimes.
